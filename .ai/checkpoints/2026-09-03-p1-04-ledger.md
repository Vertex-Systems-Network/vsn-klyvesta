## Invariants implemented

- immutable posted journal/line read surfaces;
- corrections append reversal entries instead of mutating history;
- debit total equals credit total independently per currency;
- no zero/negative posting amount;
- maximum persisted money scale of eight decimal places;
- C# `decimal` only for authoritative ledger arithmetic;
- deterministic three-letter currency normalization;
- idempotency scope is actor + operation + key;
- idempotency binds to a canonical SHA-256 normalized request hash;
- duplicate retry returns the original journal;
- changed payload under the same idempotency scope fails closed;
- only one independent reversal may be posted for an original entry in this bounded store;
- journal retains actor, operation, correlation and idempotency evidence;
- store contract exposes no update/delete/remove mutation methods.
